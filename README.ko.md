## 저장소 사용 방법

1. 아래의 카테고리 목록에서 시작하여 사용 사례와 일치하는 섹션을 여십시오.
2. 단순히 피사체뿐만 아니라 카메라 로직, 타이밍, 환경 디자인, 일관성 지침을 기준으로 프롬프트를 비교하십시오.
3. 구조를 먼저 재사용하십시오. Seedance에서는 명사를 바꾸는 것보다 샷 진행과 모션 컨트롤이 더 중요한 경우가 많습니다.
4. `@image1` 또는 `<<<Image1>>>`과 같이 의도된 구문의 일부인 프롬프트 내부 토큰은 유지하십시오.
5. 정리된 데이터 세트 내의 주요 탐색 앵커로 제목, 카테고리 및 소스 링크를 사용하십시오.
