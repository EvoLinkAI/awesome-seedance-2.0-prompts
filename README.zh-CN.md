## 如何使用本仓库

1. 从下方的分类列表中开始，打开与您用例匹配的部分。
2. 通过摄像机逻辑、时机、环境设计和一致性指令来比较提示词，而不仅仅关注主体内容。
3. 优先复用结构。在 Seedance 中，镜头推进和运镜控制往往比替换名词更重要。
4. 当提示词内部的标记（如 `@image1` 或 `<<<Image1>>>`）是预期语法的一部分时，请保留它们。
5. 使用标题、类别和来源链接作为已整理数据集内的主要导航锚点。
