## Comment utiliser ce dépôt

1. Commencez par la liste des catégories ci-dessous et ouvrez une section qui correspond à votre cas d'utilisation.
2. Comparez les prompts par logique de caméra, timing, conception d'environnement et instructions de cohérence — pas seulement par sujet.
3. Réutilisez la structure en premier. Dans Seedance, la progression du plan et le contrôle du mouvement comptent souvent plus que l'échange de noms.
4. Gardez les jetons internes au prompt tels que `@image1` ou `<<<Image1>>>` lorsqu'ils font partie de la syntaxe prévue.
5. Utilisez les titres, les catégories et les liens sources comme ancres de navigation principales dans le jeu de données nettoyé.
