## 如何使用本倉庫 (How to Use This Repository)

1. 從下方的分類列表中開始，打開與您用例相符的章節。
2. 通過鏡頭邏輯、節奏、環境設計和一致性指令來比較提示詞——而不僅僅是按主題。
3. 先復用結構。在 Seedance 中，鏡頭推進和運動控制通常比替換名詞更重要。
4. 當提示詞內部的 token（如 `@image1` 或 `<<<Image1>>>`）屬於預期語法的一部分時，請保留它們。
5. 使用標題、分類和來源連結作為清理數據集內的主要導航錨點。
